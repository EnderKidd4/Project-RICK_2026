Hello World! This is my first major solo robotics project : Making an RC Car from scratch!

Hardware:

  -  Arduino Uno
   
  -  L298N motor driver (x2)
   
   - DC Hobby Motor (x4)
   
   - Mechanum wheels (x4 [2AA, 2BB])
   
   - IR Remote
   
   - IR Sensor

   - 3D Printed Components

  Libraries:   IRremote.h |
